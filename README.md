# UCSM Mobile · SM-HUB

Aplicación móvil desarrollada en **Flutter / FlutterFlow** orientada a centralizar información y funcionalidades útiles para estudiantes de la Universidad Católica de Santa María.

## Descripción

SM-HUB es un proyecto académico y de portafolio enfocado en explorar el desarrollo de aplicaciones móviles modernas. El objetivo es construir una solución práctica, organizada y escalable, aplicando conceptos de interfaz, navegación, gestión de datos y experiencia de usuario.

## Objetivos del proyecto

- Diseñar una aplicación móvil funcional con enfoque universitario.
- Aplicar fundamentos de desarrollo móvil con Flutter.
- Trabajar con una estructura clara para futuras mejoras.
- Convertir el proyecto en evidencia profesional para portafolio.

## Stack utilizado

| Capa | Tecnología |
|---|---|
| Desarrollo móvil | Flutter |
| Generación visual | FlutterFlow |
| Lenguaje | Dart |
| Control de versiones | Git · GitHub |

## Posibles funcionalidades

- Pantallas informativas para estudiantes.
- Navegación entre módulos.
- Interfaz adaptable y moderna.
- Base para integración futura con servicios externos.

## Estado

Proyecto en desarrollo. Este repositorio puede seguir creciendo con nuevas pantallas, integración de backend, autenticación y mejoras de experiencia de usuario.
